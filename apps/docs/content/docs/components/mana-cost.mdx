## Installation

```npm
npx shadcn@latest add https://suryarastogi.github.io/manaui/r/mana-cost.json
```

The CLI adds `@import "mana-font/css/mana.min.css";` to your global CSS. The symbols need it.

## Usage

Pass a Scryfall mana cost string.

```tsx
import { ManaCost } from '@/components/manaui/mana-cost';

<ManaCost cost="{2}{W}{U}" />
<ManaCost cost={card.mana_cost} className="text-lg" />
```

Symbols scale with font size, so size them with a text utility. Hybrid (`{G/W}`), Phyrexian
(`{B/P}`), generic, `{X}` and snow costs are all supported. Split, adventure and modal cards, whose
cost reads `{2}{R} // {1}{R}`, render each face separated by `//`. A null or empty cost renders
nothing.

## Color identity

<ColorIdentityDemo />

```tsx
import { ColorIdentity, ManaSymbol } from '@/components/manaui/mana-cost';

<ColorIdentity colors={card.color_identity} />
<ManaSymbol symbol="s" />
```

`ColorIdentity` sorts the letters into WUBRG order whatever order you pass, and shows the colorless
pip for an empty identity. It has an accessible name such as "Color identity: White, Blue".
