## Installation

```npm
npx shadcn@latest add https://suryarastogi.github.io/manaui/r/card-badges.json
```

## Usage

```tsx
import {
  KeywordChips,
  ProducedManaPips,
  RarityDot,
  StapleChip,
} from '@/components/manaui/card-badges';

<RarityDot rarity={card.rarity} />
<StapleChip edhrecRank={card.edhrec_rank} />
<ProducedManaPips card={card} />
<KeywordChips keywords={card.keywords} />
```

Each badge renders nothing when its data is missing, so you can place them unconditionally.

## The badges

| Badge | Shows | Renders nothing when |
| --- | --- | --- |
| `RarityDot` | A coloured dot: grey common, silver uncommon, gold rare, orange-red mythic. | The rarity is missing or unknown. |
| `StapleChip` | "Staple" for an EDHREC rank of 1000 or better, "Deep cut" beyond 20000. | The rank is in between or missing. |
| `ProducedManaPips` | The colours a land or artifact taps for, in WUBRG then colorless order. | The card makes no mana, or is not a land or artifact (unless `always`). |
| `KeywordChips` | Up to four keyword chips, then "+N". | There are no keywords. |
