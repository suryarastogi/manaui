manaui is a small set of components for building Magic: The Gathering apps in React. They take
[Scryfall](https://scryfall.com/docs/api) card objects as input, are styled with Tailwind CSS, and
are distributed the [shadcn/ui](https://ui.shadcn.com) way: you copy the source into your project
and own it.

The logic behind them (mana cost parsing, art-crop URLs, preview timing) lives in
[`@manaui/core`](/docs/core), a dependency-free TypeScript package you can use on its own.

## Design principles

- **Text before image.** Card images are slow and card text is already in hand. Every preview opens
  on the rules text and brings the image in afterwards, never the other way round.
- **Never swap content under a reader.** When the image is about to replace the text, a ring fills
  first. A touch on the text holds it.
- **Density follows the container.** Rows switch between a compact desktop line and a phone tile
  based on the width of the list, not the viewport, so a narrow side panel on a wide screen gets the
  right layout.
- **No hidden requests.** Components render what you pass them. Art only loads on layouts that show
  it.
